DESCRIPTION

가이드 버튼 & 코치마크

  • 기존 가이드 접기/펼치기 버튼을 가이드 시작/종료 버튼과 코치마크 투어로 변경합니다.
  • 페이지에 대한 설명은 페이지 타이틀 하단에 고정하는 것으로 변경합니다.
프로토타입에 표시된 코치마크 문구는 예시입니다. 실제 노출 문구는 탭의 내용을 기준으로 합니다.

1버튼 상태

상태라벨동작
기본가이드 시작클릭 시 코치마크 1단계부터 시작
실행 중가이드 종료클릭 시 즉시 종료, 기본 상태로 복귀

동일한 버튼이 두 상태를 토글합니다. 위치는 페이지 헤더 우측 상단 고정.

2코치마크 동작 원칙

  1. 안내 순서문구 상세 (전체)에 작성된 순번에 맞춰 노출됩니다.
  2. 말풍선 회피말풍선이 가이드 종료 버튼을 가리는 경우 아래로 자동 이동합니다.
  3. 자동 실행 없음첫 방문 여부와 무관하게 버튼을 눌렀을 때만 노출됩니다.

3코치마크 구성 요소

  1. 강조 테두리대상 영역 전체를 감싸는 2px 테두리. 안쪽을 덮거나 가리지 않습니다.
  2. 단계 표시말풍선 좌측 상단. STEP 1 / 4 형식으로 현재 순번과 전체 개수를 표기합니다.
  3. 닫기말풍선 우측 상단 ✕. 모든 단계에 노출됩니다.
  4. 타이틀강조 중인 영역의 이름. 한 줄, 명사형으로 작성합니다.
  5. 서브텍스트해당 영역이 무엇을 하는 곳인지 설명하는 본문. 1~2문장을 권장합니다.
  6. 보조 설명회색 박스. 예외 상황이나 참고 정보가 있을 때만 추가하는 선택 영역입니다.
  7. 데이터 샘플데이터가 들어가는 영역 단계에서 노출하는 예시 이미지.
  8. 진행 표시말풍선 하단 좌측 도트. 전체 단계 수와 현재 위치를 나타냅니다.
  9. 버튼 영역말풍선 하단 우측. 이전 / 다음 / 가이드 종료 버튼이 위치합니다.

4버튼 정의

  • 이전2단계 ~ 마지막

    직전 단계로 이동하고 해당 영역으로 화면을 스크롤합니다. 1단계에서는 비활성 상태(회색)로 노출되며 클릭되지 않습니다.

  • 다음1단계 ~ 마지막 직전

    다음 단계로 이동합니다. 강조 테두리와 말풍선이 다음 영역으로 함께 이동하며, 화면 밖이면 해당 영역이 보이도록 스크롤합니다.

  • 가이드 종료마지막 단계

    마지막 단계에서 다음 버튼 자리를 대체합니다. 클릭 시 투어를 종료하고 헤더 버튼도 가이드 시작으로 되돌아갑니다.

  • 가이드 종료 (헤더)투어 실행 중

    페이지 헤더 우측의 토글 버튼. 단계와 무관하게 언제든 즉시 종료합니다.

그 밖의 이동 · 종료 수단

  • 이동 — 키보드 ← →
  • 종료 — Esc, 말풍선 ✕, 강조 영역과 말풍선 바깥 클릭
  • 종료 시 현재 단계는 저장하지 않으며, 재시작하면 1단계부터 다시 시작합니다.

5데이터 영역 표시

업무 카드처럼 데이터가 비어 있을 수 있는 영역은, 데이터 유무와 관계없이 데이터가 들어가는 전체 영역을 border로 표시합니다.

  • 데이터가 없어도 단계를 건너뛰지 않습니다.
  • 말풍선 안에는 항상 데이터 샘플 이미지를 함께 노출해 구조를 안내합니다.
